# NLP Text Analysis

A collection of Natural Language Processing projects covering **text classification, LLM-based classification, clustering, and topic modeling**.

This repository contains two projects developed as part of a Text Mining course at **BINUS University**.

---

## 📌 Projects

### 1. Text Classification with LLM

A text classification project that applies an Indonesian pre-trained language model to classify text into predefined categories.

**Approaches covered:**

* Text preprocessing
* Exploratory data analysis
* One-stage classification
* Two-stage classification
* LLM fine-tuning
* Hyperparameter tuning
* Model evaluation

**Notebook:**
`no1_Text_Classification_LLM.ipynb`

---

### 2. Clustering & Topic Modeling

An unsupervised NLP project that analyzes text data using clustering and topic modeling techniques to identify groups and discover underlying topics within the dataset.

**Approaches covered:**

* Text preprocessing
* Exploratory data analysis
* Text representation
* Clustering
* Cluster evaluation
* Topic modeling
* Topic interpretation

**Notebook:**
`no2_Clustering_Topic_Modeling.ipynb`

## 🎯 Objectives

The projects aim to explore how NLP techniques can be applied to:

* classify textual data using transformer-based language models;
* identify patterns and groups within unlabelled text data;
* discover latent topics from collections of text;
* evaluate and interpret the resulting models.
